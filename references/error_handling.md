# 错误处理、零破坏与安全边界

## 安全边界（防误写）
1. **未点选目标表一律只读**：用户没指认 Base/Table 前，禁止任何写操作（含改字段、加列、写行）。
2. 写操作只允许在用户批准的表；跨表复制/对账等先只读拉取。
3. 目标表含财务/客户等敏感字段时，处理前提示数据范围；示例一律脱敏。
4. 删除/清空类操作：先展示摘要→用户确认→先拉快照备份→`--yes` 执行。

## 零破坏铁律
- 未获用户明确指令，不改既有表结构（改名/加列/删行/清空）。
- 同步写入默认「幂等增量」：键比对，缺补/异改/同跳过；不做整表清空重导，除非用户显式要求且先快照。

## 常见错误分支
| 错误信号 | 处理 |
|---|---|
| dws 不存在 | install_dws.ps1 → 再验证 |
| auth 失败 / token 失效 | 停止业务命令 → 授权引导 → 成功后重放 |
| 网络超时（**幂等写入**：update / 带 recordId / `upsert`·`upsert-by-key`） | 重试 ≤3 次（间隔 2s） |
| 网络超时（**create 类非幂等**） | **禁自动重试**——超时 ≠ 未执行（请求可能已落盘），重试＝重复建行；兜底＝重拉基线 → 按键分层（已存在走 update）→ 重跑 |
| API 限流 | 等待 30s 后重试一次（**仅幂等写入**）；create 类同上条兜底 |
| 批量写入单条被拒（参数 / InvalidArgument 类） | 失败粒度＝**批**（整批全丢）→ **二分到最小单元**定位坏行；好行照写、坏行记失败明细 |
| 批量写入网络 / 系统类失败 | 整批记失败、**不二分**（避免空跑百余次请求）→ 走幂等分档重试 / 基线重跑 |
| 建字段返回 not supported（公式等） | 记录受限项，提示改 UI 配置 |
| 字段类型不匹配 | 尝试转换 → 失败 → 以 text 兜底并明确提示 |
| Base/Table 不存在/无权限 | 列出可选项请用户确认 |
| 记录单批超限/超长 | 分批 ≤100；用 --records-file |
| 关联字段创建失败 | 先按实测排查原因（主键/同 Base 约束等）；确为平台限制再降级文本并在报告说明（勿默认降级） |

> 重试与兜底按**幂等性分档**（2026-09-24 采纳 EV-202609-27）：非幂等 create 禁自动重试（「超时 ≠ 未执行」）；批量失败粒度＝批——参数类二分定位、网络 / 系统类不二分。与 verification-protocol.md §4-L「执行凭证对账」同源。

## 异常兜底
- 未捕获异常写入 `%TEMP%\dws_skill_error.log`，提示用户查看/联系管理员；优雅退出不中断 WorkBuddy。
- 不要无限重试、不要绕过 dws 用 curl 直连钉钉业务 API。
