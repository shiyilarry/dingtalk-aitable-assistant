# 钉钉AI表格平台约束（版本矩阵与实测红线）

> 方案设计前必须追问用户 AI 表格版本；追问后仍不确定 → 按**免费版**设计。

## 版本行数/列数/自动化上限（用户实测口径 2026-09-07 确认）
| 版本 | 单表最大行数 | 自动化节点/月 |
|---|---|---|
| 免费版 | 20,000 | 500 |
| 企业版 | 30,000（需求文档口径，待实测确认） | 50,000 |
| **旗舰版** | **50,000**，可联系钉钉官方销售扩容至最高 **1,000 万行** | **500,000** |

- 所有版本单表字段上限：**300 列，固定不变——官方确认当前无任何付费扩容通道**（经与钉钉销售团队确认）。
- 实测红线：**约 4.2 万行**即出现卡顿/崩溃/计算错误；即使行数扩容，仍建议热表 ≤4 万行，接近上限采用归档/分片（按月归档静态表、冷热分离）。

## 写入与配额经验
- record 单批写入 ≤100；删除单批 ≤100 且不可逆（--yes）。
- 单次查询默认 100 条/页，分页用 nextCursor。
- 自动化节点配额见上表（旗舰 50 万次/月）；大并发/高频写入需错峰。
- 记录中空键（如年月为空）会导致查找引用结果全空（"1899-12"现象），建行先补键列。

## 能力提醒
- CLI（v1.0.61+ 实测；完整能力面与用法见 `dws_command_ref.md`）已支持：视图 / 仪表盘 / 图表 / 表单基础 / **workflow 自动化 DSL** / **服务端聚合（record stats·group-stats）** / psql 只读 SQL 等。
- 仍为 UI 专属：公式字段创建、按钮字段、OCR、单选「同步其他表选项」。
- 行列数很大的宽表（如 60+ 月度列）仍适用，注意分批与预览。
